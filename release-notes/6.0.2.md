## 6.0.2: safer and quieter

Google Play Protect was flagging Zamoled as harmful. The likely cause was my own doing: version 6.0 added a feature that downloaded an update and installed it from inside the app, which needs Android's "install apps" permission. That is exactly what malware does, even though this app only ever fetched its own releases. It is gone.

- Removed the "install apps" permission and the built-in installer. Updates now open the download in your browser, and you tap the finished file; Android's own installer does the rest. Update checks and notifications still work.
- Network traffic is HTTPS only, and the app only talks to GitHub.
- Backups are off: nothing from the app is copied to cloud backups or another phone.
- Code is no longer renamed and scrambled when the app is built, and an encrypted metadata block is no longer added. A wallpaper app has nothing to hide.
- Only the signed release app is published now. The debuggable test build is gone.
- Every release lists the file's SHA-256 and the signing certificate's SHA-256 so you can check a download.

If Play Protect still shows a warning because the app is not from the Play Store, choose "Scan app" or "Install anyway". You can also report it as safe from the warning screen.
