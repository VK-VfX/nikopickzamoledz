## What's new in 6.0.1: smooth scrolling

Scrolling through the wallpaper feed is now smooth. Previews used to compete with the screen for the phone's processor; now they are drawn quietly in the background.

- Previews draw on two low-priority background threads, so scrolling always comes first.
- A card waits a moment before its preview is drawn, so wallpapers you flick past cost nothing.
- When the feed is still, the rest of the batch is drawn ahead of time, so you scroll into finished pictures.
- Lighter cards: no per-card cross-fade, no endless spinning on the category tiles.
- A baseline profile makes the first scrolls faster after installing.
- New: Windows version (below).

## Zamoled for Windows

The same wallpaper generators, drawn at your monitor's own shape and size. Browse every world, tune palette, detail and black level, type your own words, then save a PNG at your screen size, 1080p, 1440p or 4K, or set it as your desktop wallpaper in one click. Favorites are kept between runs.

Download `Zamoled-Windows-x64.zip` below, unzip it anywhere and run `Zamoled.exe`. The first start takes about 15 seconds while the renderer wakes up. It is about 500 MB because it carries Android's graphics engine, so every picture matches the phone exactly. Windows may say it does not recognise the app: choose More info, then Run anyway.

## New in 6.0

- Update the app from inside it: Settings checks for new versions, downloads them with progress and installs them over the old one. It can also check by itself and send one notification.
- A new look: condensed headings, small mono captions, leaf-shaped cards and a floating dock.
- Pixel Galaxy, a Galaga-style space battle. Pixel Quest redrawn to fit the home screen.
- Cat Club with new cat toys, and Space Doodles with nine new characters.
- Corrupted code that fades and disappears; code wallpapers with hidden easter eggs.
- A smoother black-level pass and quick presets for Detail and Black level.

## Install on Android

Download `zamoled-release.apk` on your phone and open it. New versions install over the old one. `zamoled-debug.apk` is a slower testing build that installs as a separate app.
