Generative pitch-black AMOLED wallpapers for Android 10+, and a Windows desktop app.

**Install on Android:** download `zamoled-release.apk` below on your phone and open it (allow installs from your browser if asked). New versions install over the old one. The app tells you when one is out; Settings, then Check for updates.

**Install on Windows:** download `Zamoled-Windows-x64.zip`, unzip it anywhere and run `Zamoled.exe`.
