Generative pitch-black AMOLED wallpapers for Android 10+, and a Windows desktop app.

**Install on Android:** download `zamoled-release.apk` below on your phone and open it (allow installs from your browser if asked). New versions install over the old one, and from 6.1 on the app can download and install them for you from Settings.
`zamoled-debug.apk` is a debuggable build for testing; it installs as a separate app and is slower.

**Install on Windows:** download `Zamoled-Windows-x64.zip`, unzip it anywhere and run `Zamoled.exe`.
